How I work

Four habits behind my QC work. Edit these so they sound like you.

Traceable by default

Every value in a submission should lead back to its source, the way every dish in a good kitchen traces back to a supplier.

Write for the reviewer

A reviewer opens my documents cold. I explain data choices in plain language so they do not have to guess.

Catch it early

An error found at the form stage costs a conversation. Found at submission, it costs weeks.

Standards are a shared language

CDISC lets a sponsor and a regulator read the same data the same way. I treat it as a language to speak well.
